# Cat_fact

A simple web project that uses the **Fetch API** to retrieve random cat facts from an external API and display them on the webpage.

## About the Project

**Cat Fact** is a beginner-friendly JavaScript project focused on learning how to work with APIs and asynchronous data.

The application fetches cat-fact data from an external API using JavaScript's **Fetch API** and displays the result through a simple user interface.

## Tech Stack

* **JavaScript** – Core functionality, API requests, and DOM manipulation
* **HTML5** – Structure of the webpage
* **CSS3** – Styling and user interface
* **Fetch API** – Fetching cat-fact data from an external API

## Features

*  Fetch random cat facts
*  Retrieve data from an external API
*  Dynamic content using JavaScript
*  Simple and responsive user interface
*  Fetch new facts without reloading the page
